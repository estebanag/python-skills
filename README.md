# Python Skills

A Python quality profile designed to compose with [Matt Pocock's engineering skills](https://github.com/mattpocock/skills).

## Usage

Run the one-time manual setup command in each repository:

```text
/setup-python-quality
```

After setup, call any applicable engineering skill together with `python-quality`.
